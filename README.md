# YandexLavkaCalories (MVP)

Userscript, который показывает **примерное количество ккал** товаров в корзине
Яндекс Лавки прямо на странице `lavka.yandex.ru`.

## Как это работает

1. Скрипт парсит DOM корзины (название товара, количество, вес фасовки, штрихкод — если доступен).
2. Ищет калорийность в открытом бесплатном API **[Open Food Facts](https://world.openfoodfacts.org)**:
   - сначала по штрихкоду (`/api/v2/product/{barcode}.json`);
   - затем по названию через поиск (`/cgi/search.pl`).
3. Результат кэшируется в `localStorage` (30 дней), чтобы не дёргать API на каждое изменение корзины.
4. Формула: `ккал = (ккал на 100 г × вес фасовки в г × количество) / 100`.
5. Рядом с блоком «Итого» появляется виджет: суммарные ккал, покрытие данными
   («известно для N из M») и детализация по товарам.

Приватные API Яндекс Лавки **не используются** — только открытый API и чтение верстки вашей собственной страницы.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) в браузер.
2. Откройте Tampermonkey → «Добавить новый скрипт».
3. Скопируйте содержимое файла [`lavka-calories.user.js`](./lavka-calories.user.js) и сохраните (Ctrl+S).
4. Откройте корзину на `https://lavka.yandex.ru` — при наличии товаров должен появиться виджет с ккал.

## Как подобрать селекторы (важно для MVP)

Яндекс Лавка — SPA, классы вёрстки регулярно меняются. Если виджет не появился
или товары не находятся:

1. Откройте корзину → F12 → вкладка **Elements**.
2. Найдите карточку товара в корзине и посмотрите её атрибуты (`data-qa`, `data-auto` и т.п.).
3. Обновите значения в объекте `CONFIG` в начале скрипта:
   - `itemSelector` — контейнер одного товара в корзине;
   - `nameSelector` — элемент с названием внутри карточки;
   - `qtySelector` — блок с количеством.
4. Сохраните скрипт и обновите страницу.

Если пришлёте фрагмент HTML карточки товара из DevTools, селекторы можно поправить точно.

## Ограничения MVP

- Точность оценочная: данные Open Food Facts вносят волонтёры, покрытие российскими товарами неравномерное.
- Товары без найденных данных показываются как «нет данных» — итог считается только по известным позициям.
- Если вес фасовки не удалось извлечь ни из верстки, ни из API, позиция не учитывается.
- Работает только в веб-версии Лавки (мобильное приложение не покрыто).
